# 投稿タイプ

以下から最適なものを1つ選択してください。

- daily
  日常・生活・洗濯あるある

- emotion
  香り・感情・記憶・清潔感・人間関係

- question
  質問・会話・ユーザー参加型

- knowledge
  洗濯に関する知識・豆知識・ハウツー

- problem
  洗濯に関する悩み・問題提起・解決策

- review
  商品レビュー・使用感・特徴紹介

- sale
  セール・値下げ・お買い得情報

# 基本方針

1. 商品紹介を目的として投稿テーマを決めない。
2. ユーザーが読みたい・反応したいテーマを優先する。
3. 商品を登場させる必然性がない場合、商品を登場させない。
4. 商品投稿が連続しないようにする。
5. 直近の投稿とテーマ・構成・表現が重複しないようにする。
6. 「香り」は、単なる商品特徴ではなく、感情・記憶・清潔感・人間関係などと結びつけることを検討する。
7. 「部屋干し」「生乾き」「臭い」などの悩みは、具体的な解決策につなげる。
8. 質問投稿では、無理に商品を紹介しない。
9. セール投稿では、「安い」だけではなく「今買う理由」を作る。
10. Amazonへの誘導は、必要性が生まれた場合のみ行う。

# 投稿比率の目安

長期的な投稿バランスとして、以下を目安としてください。

- 日常・あるある：20%
- 香り・感情：20%
- 質問・会話：15%
- 洗濯知識：15%
- 悩み解決：15%
- 商品紹介：10%
- セール：5%

ただし、今回の商品・季節・直近投稿などを考慮し、この比率から柔軟に変更してください。

# 各項目

post_type:
選択した投稿タイプ

theme:
今回扱う具体的なテーマ

purpose:
この投稿によって狙うもの
例：共感、コメント、保存、商品興味、購入

hook_direction:
冒頭で何を提示するか

structure:
投稿の構成を順番に記述

product_usage:
商品をどの程度登場させるか

amazon_cta:
Amazonへの誘導強度

reason:
なぜ今回この投稿戦略を選択したのか

avoid:
今回の投稿で避けるべき表現・構成
