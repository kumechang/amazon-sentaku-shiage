# チェック項目

以下をそれぞれ0〜10点で評価してください。

1. 相手の投稿内容への的確さ(一般論で返していないか)
2. 会話としての自然さ
3. 共感性
4. 長さの適切さ(1〜2文程度)
5. 宣伝臭の低さ
6. 誇張の少なさ
7. 上から目線でないか
8. ペルソナとの一貫性

# 特に確認すること

- 商品名やAmazonリンクに触れていないか
- 架空の体験を語っていないか(実際に使っていない商品について「使ってみた」等と書いていないか)
- 根拠のない効果を主張していないか
- 相手を否定する表現がないか
- センシティブな話題(政治・宗教・差別・性的な話題・犯罪など)に触れていないか
- 「わかる」「それ気になる」など、不自然に繰り返す定型文になっていないか

{{pass_threshold_note}}

基準未満の場合は、問題点を修正したリプライ案を作成してください。

# 出力

JSONのみを出力してください。

{
  "score": 0,
  "pass": true,
  "problems": [],
  "improvements": [],
  "final_reply": ""
}

## 各項目

score:
チェック項目の合計(0〜80点)

pass:
合格基準を満たしたか(true/false)

problems:
指摘事項(問題なければ空配列)

improvements:
改善点(問題なければ空配列)

final_reply:
最終的なリプライ案。合格の場合は元の案そのまま、不合格の場合は問題点を修正した版。
